# DevArena-Week-6

## Overview
This project focuses on performing statistical analysis using Python to extract meaningful insights from a given dataset. The primary objective is to apply descriptive statistics, data preprocessing, and analytical techniques to understand data distributions, relationships, and patterns.<br>
During the preprocessing stage, the dataset was cleaned and prepared by handling missing values, correcting data types, and structuring the data for analysis. Key statistical measures such as mean, median, variance, and standard deviation were computed to summarize the data and identify central tendencies and dispersion.<br>
The analysis also explores relationships between variables using correlation techniques and visual representations. Various plots were generated to better understand trends, distributions, and outliers within the dataset.
Overall, this project demonstrates how statistical methods and Python libraries can be effectively used to transform raw data into interpretable insights, supporting data-driven decision-making.

## Files
- data/
    - `uber_data.csv` - <b>CSV file</b> that contains the data we analysed for insights and recommendation in this project.

- `hypothesis_test_result.txt` - Consist of results and the verdict we derived from three different test on the given data.

- `README.md` - This file.

- `statistical_analyis.ipynb` - Main <b>Python Notebook</b> showing the <b>exploratory data analysis</b> done on the data and different visualizations picturising the insights generated from the data along with the hypothesis testing with three different types of test.

- `requirements.txt` - Consist of <b>Python libraries</b> required for this project.

## Structure     
In this project, a comprehensive statistical analysis workflow was implemented using Python to perform Exploratory Data Analysis (EDA) and derive meaningful insights from the dataset.<br>

During the preprocessing phase, the data was cleaned and structured, including handling missing values and ensuring proper formatting. This step ensured that the dataset was suitable for accurate statistical computations.<br>

The analysis begins with descriptive statistics, where key metrics such as mean, median, standard deviation, and variance were calculated to summarize the dataset and understand its overall behavior.<br>

Further analysis includes distribution analysis, where visualizations such as histograms and box plots were used to identify patterns, skewness, and potential outliers in the data.<br>

A correlation analysis was also conducted to examine relationships between variables. This helps in identifying dependencies and understanding how different features influence each other.<br>

Visualization plays a key role in the project, with graphs used to represent statistical findings clearly and effectively. These visual tools enhance interpretability and make it easier to identify trends and anomalies.<br>

Overall, this project integrates data preprocessing, statistical computation, and visualization techniques to provide a structured approach to analyzing data. The insights generated can be used for better understanding of the dataset and supporting analytical or business decisions.
